# NextStop：功能，按學生遇到它們的順序

[English](features.md) · [簡體中文](features.zh-CN.md) · **繁體中文**

NextStop 是一屏，裡面有六個時刻。這份文件按學生碰到它們的順序把這些時刻走一遍：這一天被揭示出來，被當成一張卡讀完，穿過四個動作跟進，現實動了就把它修好，提前一天編輯，在一個大部分時間都在給自己調參的頁面裡調參。

產品為什麼存在，論證在 [`why.md`](why.zh-TW.md)。規劃與修復的機制在 [`algorithm.md`](algorithm.zh-TW.md)，這裡不重複。下面每個功能都以一行說明它站在什麼上面，所以依賴可以追溯，不必跟著推導走。

## 怎麼讀這份文件

每個功能都回答同樣三個問題。

| 列 | 問題 |
|---|---|
| 做什麼 | 行為，一句話 |
| 你看到什麼 | 螢幕，按學生會描述的樣子 |
| 依據 | 它底下的那唯一一件東西，只點名，不展開 |

全文用了三個狀態詞，沒有一行寫得比它的狀態更高。

| 狀態詞 | 含義 |
|---|---|
| Built | 在 `product/demo/index.html` 的 prototype 裡跑著 |
| Data layer | 由 Spring 服務回答，見 [`architecture.md`](architecture.zh-TW.md) |
| Specified | 設計過、沒實現，整個修復路徑都算在這裡 |

有兩條規則適用於每一屏，不在每個功能裡重複。

- **空白從來不是空的。** 它要麼被一個停留點填上，要麼被並進鄰近的塊。沒有 wait 型別，也沒有佔位行要你填。
- **四個動作，只有四個。** 沒有第五個，一個 class block 只拿到其中一個。

## 1. 揭示這一天

一天裡第一次開啟，是唯一一次會算出東西的開啟。

| 功能 | 做什麼 | 你看到什麼 | 依據 |
|---|---|---|---|
| 只揭示一次 | 第一次開啟就把一整天規劃好，之後再不算一遍 | 一個已經完成的一天，沒有 spinner，也沒有空白表單 | Specified，planner 還是 stub，見 algorithm 第 9 節 |
| 只讀一次位置 | 只在揭示時讀一次位置，之後不跟蹤 | 之後什麼都沒發生，也沒有第二次許可權請求 | Specified |
| 沒有位置時的退路 | 退回最後一節課的教學樓，再退回三個樓名 | 三個樓名，這是這一天唯一會問的問題 | Specified |
| 結束在最後一件事上 | 計劃結束在學生答應要去的最後一件事上，不在關門時間上 | 「直到 18:20」，跟著課表走，不跟時鐘走 | Built，作為上界，anchor 來自 sample feed |
| 之後只讀 | 之後再開啟只把已經持有的這一天渲染出來，什麼都不算 | 你離開時的那張卡，你離開時的那個狀態 | Built，計劃活在標籤頁裡 |
| 一次只一天 | 揭示時重建計劃，絕不把它帶過夜 | 今天總是從頭開始 | Built |

揭示的輸出是一個序列，不是一個集合。具體說：09:00 在 KB 上課，11:00 在 KB 227 自習，12:10 午飯，14:00 在 CPD 上課。為 11:00 做的選擇，決定了 13:50 學生站在哪棟樓裡，這就是一串空房間列不出來它的原因。

## 2. 一張卡

首頁沒有工具欄，也沒有表單。它有一張卡，和卡下面的那一天。

| 功能 | 做什麼 | 你看到什麼 | 依據 |
|---|---|---|---|
| 那張卡 | 把當前停留點顯示成一個時間和一個地點，帶上步行時間和該出發的時刻 | 「KB 227 · until 12:00」和它下面的「walk 5 min」 | fill 層，algorithm 裡的 L3 |
| 下面那一疊 | 把這一天剩下的壓成三到五個塊 | 時間、型別、地點的行，點一下是閱讀，不是編輯 | Built |
| 步行是看得見的成本 | 每次換樓都付出成本，並把成本顯示出來 | 兩塊之間那一行上的「walk 8 min」 | 靜態步行矩陣，學出來的係數是 Specified |
| 沒有要填的東西 | 每個空白裡已經有一個停留點，預設是自習 | 沒有空行，沒有「free」，沒有要填完的欄位 | Built 在表層，作為保證是 Specified（L2） |
| 一個它不擁有的房間 | 沒有房間的會議顯示 TBD，而不是編一個房號 | 塊上寫「TBD」，外加一個動作 | Built |
| 一件沒有落定的事 | 沒訂上的會議一直懸著，看得見 | 這個塊帶一個動作，而訂好的塊帶一個房間 | Built |
| 筆畫就是狀態 | 已解決的塊是實線，外部事實是虛線，要訂的是點線 | 三種線型，絕不出現系統沒查過的塊 | Specified |

**這一屏上沒有的東西。** 沒有「我到了」按鈕。到達不是 app 要你做的那個手勢，因為一個只是在確認時鐘已經知道的事的點選，就是一個會被跳過的點選。塊結束時間過了就渲染成已完成，它的 sheet 回答「That block is already gone」。到達由計劃和當前時間推出，從不靠點選。

## 3. 四個動作

動作屬於塊，不屬於頁面。沒有工具欄，底欄只在 Day、Plan 和 Mine 之間切換。

| 動作 | 位置 | 做什麼 | 你看到什麼 | 依據 |
|---|---|---|---|---|
| Change | 自習、吃飯、會議 | 換掉這個停留點的地點，守住它的目的和時間 | 三個地點帶步行分鐘數和「free for the whole block」，還能按需再來更多 | 可用性來自資料層，同一性測試是 Specified |
| Skip | 只有課 | 把這個學生這一小時標為缺席，課照上，教室照樣算被佔 | 塊變灰，這一小時變成自習 | 本地 Built，重新填充是 Specified |
| Book it | 一個本來就可預約的空間裡的停留點 | 訂下房間，把結果作為一個事實寫進計劃 | 「Booked · LIB 3/F Room 2」，旁邊有 Cancel | Specified，沒有接任何預約服務 |
| End the day, stay longer | 這一天的底部 | 提前收掉計劃，或者把最後一個停留點延過它的邊界 | 這一天收成「That's the day」，旁邊有「Not yet」可以回來 | Built，兩者都餵給學出來的結束時間 |

**一個 class block 只提供其中一個。** Skip。一節 lecture 不可能被一個正在看卡的學生挪走、縮短或者換教室，所以這個塊不假裝可以。

**Claim 和 book 是兩件事，介面把它們分開。** 普通教室給一個小群體 claim：系統說它會用這個房間，claim 一下就能撤回，撤回把塊放回原處。一鍵預約只在本就對所有人可預約的地方提供。系統分配不到的房間，絕不會被渲染成已分配，所以這是兩個行為，不是一個按鈕。依據：可用性的那個回答，外加一條還不存在的預約路徑。

## 4. 偏離

每個偏離都從一個地方進來，就是螢幕頂部那一行說「Something changed?」的地方，它給的是兩句話，不是一個表單。

| 偏離 | 會發生什麼 | 你看到什麼 | 依據 |
|---|---|---|---|
| 遲到了，還在空白之內 | 開啟的停留點邊界移動，這一天其餘的部分不動 | 卡片就地重寫，寫「One block changed · the rest untouched (ends 10:46)」 | Specified，algorithm 第 4 節的梯子 |
| 只改這一個 | 只有選中的停留點地點變，目的和時間守住 | 「Moved to KB 221 · only this block changed」 | 資料層，同一性測試是 Specified |
| 超時超掉整個空白 | anchor 贏，停留點被取消，它的時間並進了步行，下一節課遲到到場 | 少一個塊，一天變短，沒有縮短的課 | Specified，rank 4 加上 L2 裡的合併 |
| Undo | 每次寫入都記錄它替換掉了什麼，一點就還原 | 通知上的「Undo」，只在幾秒之內 | Built |
| 和完整重算比一比 | 把同一個偏離放進去重算一遍，兩個計數都擺出來 | 「see full recompute」，然後「Full recompute: 3 blocks changed」 | Specified，作為一個測試開關 |

這五個共用一種舉止。重新整理是就地發生的，沒有模態，沒有確認，也不問為什麼。一個要花掉一個對話方塊的改動，代價比改動本身更大。

跳過一節課不是修復的輸入。它是第 3 節裡的 skip 動作，planner 繞著它規劃，但從不自己產生一個。

這個機制的詞是修復，它的停止條件是一個關於「相同」的定義：同樣的目的，步行容忍範圍內同一棟樓，開始時間在十五分鐘以內。任何過不了這個測試的東西，都在壞掉的那個視窗裡重新求解，視窗再和它的鄰居對一遍，計劃其餘部分原地不動。依據：[`algorithm.md`](algorithm.zh-TW.md) 第 3、4、5 節。這些在 prototype 裡一條都沒有，那裡一個偏離就是一次固定的邊界位移。

## 5. Plan 頁

第二個標籤頁，是提前一天用的，不是當天用的。

| 功能 | 做什麼 | 你看到什麼 | 依據 |
|---|---|---|---|
| 五個周列 | 把工作周鋪成五個窄列，一個塊一條 bar | 五列，今天畫下劃線，bar 帶出每一天的形狀 | Built |
| 當天列 | 列出選中的那一天，開始時間放在左邊距裡，地點放在行裡 | 時間一路排下去在左邊，型別和房間橫過來 | Built |
| 開始和結束 | 今天頭部的兩個可編輯邊界 | 「Today from 09:00 until 18:20」，點一顆藥丸，從 07:00 到 23:00 裡挑一個半點 | Built，而且它餵給揭示 |
| 只有今天可編輯 | 其他每一天都標成只讀 | 編輯控制元件本該在的地方寫著「only today can be edited」 | Built |
| 點一個塊就改它 | 開啟日屏用的同一個 sheet | 四個動作，範圍限於那個塊 | Built |
| 手動加 | 加一個塊，然後把它兩邊的空白填上 | 「+ Add manually」，一個型別和兩個時間 | Built，放置是 Specified |
| 一句話 | 接一段描述出來的改動，先預覽它會做什麼，再應用 | 「Make tomorrow afternoon study time, back in the lab by 3」，然後「What it did (preview)」和 Apply | Specified，預覽今天還只是一行固定文字 |

有兩件事比佈局更重要。這一頁從不顯示沒解決的塊，所以手動加的自習塊會先被重新求解到一個房間，才被顯示成有房間。這一頁編輯的計劃就是日屏讀的那一份，所以這裡的編輯可以在那邊撤掉。

## 6. Mine

這裡放兩樣東西，你可以改的引數，和它正在改的引數。

| 功能 | 做什麼 | 你看到什麼 | 依據 |
|---|---|---|---|
| 可編輯的引數 | 把 planner 讀的那些數字攤開，帶上當前值 | 步行速度作為一個係數，工作日通常的結束時間，通常的午飯地點，每個都帶 Save | Built，被 Specified 的規劃消費 |
| 它在學你 | 從動作裡推出同樣的值，而不是問你要 | 「walk × 1.14 · 3 observations before it replaces the default」 | Specified，沒有埋點 |
| 證據有個下限 | 學到的值要三次觀察之後才能替換預設值 | 同一行，帶上這個計數 | Specified |
| 學習只是預設值 | 學到的值預填一個引數，不撤掉任何控制元件 | 每個動作都還在螢幕上 | Built，作為一條規則 |

學到了什麼，從什麼學的。

| 學到的 | 讀自 | 變成 |
|---|---|---|
| 你實際走多快 | 你說你遲到時的那個空白 | 更早出發，×1.00 到 ×1.28 |
| 你的一天什麼時候結束 | 結束這一天，以及你多常待久一點 | 那個工作日的預設結束時間 |
| 你去哪些地方 | 你改塊時挑了哪個選項 | 排到第一位，標成你常去的地方 |
| 你上不上某一節課 | 跳過它 | 這一小時當作只對你一個人空著 |
| 你什麼時候吃飯 | 現在挑，還是塊之後再挑 | 吃飯的那個視窗 |

讓它保持誠實的規則是：學到的東西永遠是預設值，永遠不是一個被拿走的控制元件。出勤留在本地，從不聚合，也從不拿來給誰排名。

## 沒有做出來的東西

只說一遍，這樣上面沒有一行會被讀得比它實際走得更遠。

| 沒做出來的 | 會落在哪裡 |
|---|---|
| 揭示背後的 planner | [`algorithm.md`](algorithm.zh-TW.md) 第 9 節，stub 每個空白填一個自習停留點 |
| 修復的梯子、同一性測試、鄰居檢查 | algorithm 第 4、5 節，偏離是一次固定的邊界位移 |
| 四個指標 | 沒有埋點，所以關於修復的每個數字都是示意 |
| 預訂任何東西 | 一鍵預約 是個標籤，後面沒有服務 |
| 學習 | 引數可以編輯，還沒有任何東西推出它們 |
| 真正的課表 feed | `mock-school-api` 模擬它，學校的 endpoint 沒有接 |
| 一份共享的計劃 | 計劃活在一個瀏覽器標籤頁裡，所以桌面和手機對不上 |

設計目標是每天一個手勢。上面每個功能，要麼是朝它走的一步，要麼是它身上還沒到位的一塊。

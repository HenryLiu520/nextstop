# 界面与交互规则

[English](screens.md) · **简体中文** · [繁體中文](screens.zh-TW.md)

NextStop 是一个页面，四个 tab。一天是一列块，块与块之间的接缝里是步行时间。每一个动作都住在它所改动的那个块里。

这是 `product/demo/index.html` 已经遵守的约定。原型与本文不一致时，原型胜出，本文被修正。

## 1. 四个 tab，没有别的

没有侧栏，没有工具栏，没有浮动按钮，没有搜索框，也没有设置抽屉。页头是一个 wordmark 和一行日期。列表下面有一行输入，收一句话，Day 和 Plan 上都有。不是 tab、不是块、不是接缝、不是 sheet 的东西都是刻意缺失的。

| # | Tab | 放什么 | 唯一的职责 | 从不包含 |
|---|---|---|---|---|
| 1 | **Day** | 块、接缝、块内动作、End the day / Stay longer | 99% 的打开。你看，你点，你移动 | 表单、文本输入、聊天记录 |
| 2 | **Plan** | 带负载条的周条、点一天、一句话、预览、应用 | 唯一能改变未来的地方 | 月网格、自动弹出键盘、对话记录 |
| 3 | **Find** | 把原来那个查询页整页嵌进来，看此刻哪几间空着 | 不离开一天页就能查房间 | 筛选、地图、收藏 |
| 4 | **Mine** | 学到的默认值：步行速度、周四通常几点结束、常去的午饭点 | 首次运行，以及之后你想纠正它时 | 连续打卡、评分、问卷 |

底部条 56px 高，页面底色，一条 1px 顶边框，没有图标，没有凸起的 tab。活动 tab 是墨色 `#1C1A17`，标签正中下方一个 4px 朱红点，距底 12px。tab 标签 11.5px，字距 .1em。

## 2. 一天就是块与接缝

```
  NextStop                        Something changed? Say it
  Thursday · 30 Oct
  ------------------------------------------------
  | 09:00-10:50  Class    COMP1110 · KB             |   past, 40% opacity
       :  Walk 5 min
  +-----------------------------------------------+
  |# 11:00-12:00  Study         KB 227           . |   current, enlarged
  |  You're here · until 12:00                     |
  |  [ Change ]                                    |
  +-----------------------------------------------+
       :  Walk 10 min
  : 12:10-12:40  Lunch    Chong Yuet Ming          :   dotted, not booked
       :  Walk 10 min
  +-----------------------------------------------+
  |# 14:00-15:50  Class    CPD · LG05              |
  |  [ Skip ]                                      |
  +-----------------------------------------------+
       ...

       [ End the day ]   [ Stay longer ]
```

### 2.1 块的解剖

| 元素 | 规格 |
|---|---|
| 左侧竖条 | 4px 宽，上下各内缩 11px，圆角 2，按类型着色 |
| 类型色 | Class `#1C1A17`、Study `#2F5D9E`、Lunch `#B4763A`、Meeting `#6A4C93` |
| 时间 | Georgia，14.5px，`tabular-nums`，写作 `HH:MM-HH:MM` |
| 类型标签 | 11px，`#6B655C`，距时间右侧 9px |
| 地点 | 13.5px，字重 600，推到右边缘 |
| 盒子 | 白色，1px `#E2DCCF`，圆角 12，无阴影，内边距 12 / 14 / 12 / 18 |
| 动作行 | 在块内，最后一行下方 10px，按钮之间 9px 间隙 |

### 2.2 三种状态

| 状态 | 边框 | 填充 | 含义 |
|---|---|---|---|
| 实线 | 1px `#E2DCCF` | 白色 | planner 解出来的，所以挪它是我们的事 |
| 虚线 | 1.5px `#C9C0AE` | 白色 | 外部事实：你挪不动的课，已经订好的房间 |
| 点线 | 1.5px `#BDB4A4` | 透明 | 等待预订，或等待确认 |

还有两种外观叠在这些状态之上。

过去的块降到 40% 不透明度，并在它的时间上画删除线。它留在列里，让这一天保持形状，点它会回答「那个块已经过去了」，而不是打开 sheet。

当前块是唯一被放大的块。时间到 26px，左竖条到 5px，内边距增加 3px，地点之后落一个 6px 朱红点，新增一行写着「You're here · until 12:00」。恰好一个块能拥有那个点。

### 2.3 接缝

接缝上唯一的文字是「Walk N min」。它是一条 16px 的点线竖轨，1.5px `#C9C0AE`，标签 10.5px `#8C8478`，上下各 9px 空隙，没有卡片，没有背景，没有圆角。宽度是下一个开始减上一个结束，四舍五入到 5 分钟，下限为 5。

接缝从不说「等」，从不说「空闲」，从不说「没安排」。空闲时间不是块与块之间的空隙。空闲时间会变成一个学习块。

## 3. 动作矩阵

行是块的类型。列是从那个块可达的动作。`block` 表示按钮就在块上。`sheet` 表示它是点开块之后那个 sheet 里的一行。`no` 表示从不提供。

| 块 | Skip | Change place | Book it | Nudge time | Remove |
|---|---|---|---|---|---|
| **Class** | `block` | `no` | `no` | `sheet`（±15, ±30） | `sheet` |
| **Study** | `no` | `block` | `no` | `no` | `sheet` |
| **Lunch** | `no` | `block` | `no` | `sheet`（±15, +30） | `sheet` |
| **Meeting** | `no` | `block` | `block` | `sheet`（±15） | `sheet` |
| **End of day** | `no` | `no` | `no` | `no` | `no` |

最后一行用最终块下面的两个按钮取代整套：`End the day` 与 `Stay longer`。两者都是 1px 墨色描边的胶囊按钮。两者都不用朱红，因为当前块上的点已经占用了它。

一个 class 块只显示一个按钮，`Skip`，意思是「我不去」。跳过不会删掉那个小时。那个小时变成学习时间，接缝围绕它重算。

迟到不是页面级动作。「Something changed?」打开一个 sheet，里面两个 chip，「the class ran 20 min late」与「I am 10 min behind」。两者都会缩短你正站着的那个块，并给出一条额外链接「see full recompute」，它存在的唯一目的是让局部修复能与全局修复比较。

## 4. Sheet 与撤销条

| 部分 | 规格 |
|---|---|
| Sheet | 从底部升起，顶部圆角 18，页面底色 `#FAF7F2`，左右 20px，底部 26px，最大高度 76%，内部滚动 |
| Veil | `rgba(28,26,23,.28)` 覆盖页面，点任何地方关闭 |
| 标题 | 13px 字重 600，读作 `14:00-15:50 · Class` |
| 行 | 13px，上下内边距 11px，时间用 Georgia，某行将产出的值靠右 |
| 选择器 | 恰好 3 个候选加一个 `Change` 去换一批，绝不是 10 个，绝不重复 |
| 撤销条 | 在导航之上（距底 66px），左右内缩 16px，白色，1px `#E2DCCF`，圆角 12，一句话，朱红 `Undo` 推到右边 |

| 动作 | 撤销条文案 | 撤销恢复什么 |
|---|---|---|
| Change place | `Moved to Chi Wah B1 · only this block changed` | 之前的地点 |
| Skip class | `Skipped · that time is now study` | 那节课 |
| Book | `Booked LIB 3/F Room 2 · 16:00-16:50` | 未预订的那个块 |
| Remove | `Remove this item` | 那个块 |
| Repair | `One block changed · the rest untouched (ends 11:40)` | 之前的结束时间 |
| End day | `That is the day · Thursdays usually end at 20:00` | 这一天 |

撤销条存活 6 秒后离开。同时只有一条，所以第二个动作替换文案，而不是叠出第二条。撤销是链接，绝不是按钮，且在可见期间是屏幕上唯一的朱红。

## 5. 设计 token

| 用途 | 值 |
|---|---|
| 页面 | `#FAF7F2` |
| 块 | `#FFFFFF` 配 1px `#E2DCCF`，无阴影 |
| 墨色 | `#1C1A17` |
| 次要 | `#6B655C` |
| 弱化 | `#8C8478` |
| 强调 | `#C8452D` 朱红，每屏一次 |
| 类型色 | Class `#1C1A17`、Study `#2F5D9E`、Lunch `#B4763A`、Meeting `#6A4C93` |
| 拉丁字体 | Georgia，serif |
| 中文字体 | Songti SC，回退到 Georgia |
| 数字 | 凡出现时钟时间处一律 `tabular-nums` |
| 按钮 | 34px 高，圆角 999，1px `#1C1A17`，标签 12.5px，字距 .05em |
| 圆角 | 块 12，按钮 999，sheet 18 |
| 栅格 | 页边 20px，节奏 8px |

## 6. 三条规则

**动作属于块，不属于页面。** 按钮绝不停在屏幕底部，指望它作用于你最后碰过的东西。如果从按钮所在的位置看不到它要改动的那件事，那这个按钮就是错的。

**朱红每屏只出现一次。** 它标记那唯一活着的东西：当前块上的点、活动 tab 的点、撤销链接，或一条警告。一屏两个红标记，说明设计已经答不上「我现在在哪」。

**不存在空时间这种东西。** planner 不留洞，界面也从不画洞。未预订的小时变成学习，学习块拉长去填满接缝。容许留洞会把产品变回一个课表查看器。

# NextStop：功能，按学生遇到它们的顺序

[English](features.md) · **简体中文** · [繁體中文](features.zh-TW.md)

NextStop 是一屏，里面有六个时刻。这份文档按学生碰到它们的顺序把这些时刻走一遍：这一天被揭示出来，被当成一张卡读完，穿过四个动作跟进，现实动了就把它修好，提前一天编辑，在一个大部分时间都在给自己调参的页面里调参。

产品为什么存在，论证在 [`why.md`](why.zh-CN.md)。规划与修复的机制在 [`algorithm.md`](algorithm.zh-CN.md)，这里不重复。下面每个功能都以一行说明它站在什么上面，所以依赖可以追溯，不必跟着推导走。

## 怎么读这份文档

每个功能都回答同样三个问题。

| 列 | 问题 |
|---|---|
| 做什么 | 行为，一句话 |
| 你看到什么 | 屏幕，按学生会描述的样子 |
| 依据 | 它底下的那唯一一件东西，只点名，不展开 |

全文用了三个状态词，没有一行写得比它的状态更高。

| 状态词 | 含义 |
|---|---|
| Built | 在 `product/demo/index.html` 的 prototype 里跑着 |
| Data layer | 由 Spring 服务回答，见 [`architecture.md`](architecture.zh-CN.md) |
| Specified | 设计过、没实现，整个修复路径都算在这里 |

有两条规则适用于每一屏，不在每个功能里重复。

- **空白从来不是空的。** 它要么被一个停留点填上，要么被并进邻近的块。没有 wait 类型，也没有占位行要你填。
- **四个动作，只有四个。** 没有第五个，一个 class block 只拿到其中一个。

## 1. 揭示这一天

一天里第一次打开，是唯一一次会算出东西的打开。

| 功能 | 做什么 | 你看到什么 | 依据 |
|---|---|---|---|
| 只揭示一次 | 第一次打开就把一整天规划好，之后再不算一遍 | 一个已经完成的一天，没有 spinner，也没有空白表单 | Specified，planner 还是 stub，见 algorithm 第 9 节 |
| 只读一次位置 | 只在揭示时读一次位置，之后不跟踪 | 之后什么都没发生，也没有第二次权限请求 | Specified |
| 没有位置时的退路 | 退回最后一节课的教学楼，再退回三个楼名 | 三个楼名，这是这一天唯一会问的问题 | Specified |
| 结束在最后一件事上 | 计划结束在学生答应要去的最后一件事上，不在关门时间上 | 「直到 18:20」，跟着课表走，不跟时钟走 | Built，作为上界，anchor 来自 sample feed |
| 之后只读 | 之后再打开只把已经持有的这一天渲染出来，什么都不算 | 你离开时的那张卡，你离开时的那个状态 | Built，计划活在标签页里 |
| 一次只一天 | 揭示时重建计划，绝不把它带过夜 | 今天总是从头开始 | Built |

揭示的输出是一个序列，不是一个集合。具体说：09:00 在 KB 上课，11:00 在 KB 227 自习，12:10 午饭，14:00 在 CPD 上课。为 11:00 做的选择，决定了 13:50 学生站在哪栋楼里，这就是一串空房间列不出来它的原因。

## 2. 一张卡

首页没有工具栏，也没有表单。它有一张卡，和卡下面的那一天。

| 功能 | 做什么 | 你看到什么 | 依据 |
|---|---|---|---|
| 那张卡 | 把当前停留点显示成一个时间和一个地点，带上步行时间和该出发的时刻 | 「KB 227 · until 12:00」和它下面的「walk 5 min」 | fill 层，algorithm 里的 L3 |
| 下面那一叠 | 把这一天剩下的压成三到五个块 | 时间、类型、地点的行，点一下是阅读，不是编辑 | Built |
| 步行是看得见的成本 | 每次换楼都付出成本，并把成本显示出来 | 两块之间那一行上的「walk 8 min」 | 静态步行矩阵，学出来的系数是 Specified |
| 没有要填的东西 | 每个空白里已经有一个停留点，默认是自习 | 没有空行，没有「free」，没有要填完的字段 | Built 在表层，作为保证是 Specified（L2） |
| 一个它不拥有的房间 | 没有房间的会议显示 TBD，而不是编一个房号 | 块上写「TBD」，外加一个动作 | Built |
| 一件没有落定的事 | 没订上的会议一直悬着，看得见 | 这个块带一个动作，而订好的块带一个房间 | Built |
| 笔画就是状态 | 已解决的块是实线，外部事实是虚线，要订的是点线 | 三种线型，绝不出现系统没查过的块 | Specified |

**这一屏上没有的东西。** 没有「我到了」按钮。到达不是 app 要你做的那个手势，因为一个只是在确认时钟已经知道的事的点击，就是一个会被跳过的点击。块结束时间过了就渲染成已完成，它的 sheet 回答「That block is already gone」。到达由计划和当前时间推出，从不靠点击。

## 3. 四个动作

动作属于块，不属于页面。没有工具栏，底栏只在 Day、Plan 和 Mine 之间切换。

| 动作 | 位置 | 做什么 | 你看到什么 | 依据 |
|---|---|---|---|---|
| Change | 自习、吃饭、会议 | 换掉这个停留点的地点，守住它的目的和时间 | 三个地点带步行分钟数和「free for the whole block」，还能按需再来更多 | 可用性来自数据层，同一性测试是 Specified |
| Skip | 只有课 | 把这个学生这一小时标为缺席，课照上，教室照样算被占 | 块变灰，这一小时变成自习 | 本地 Built，重新填充是 Specified |
| Book it | 一个本来就可预约的空间里的停留点 | 订下房间，把结果作为一个事实写进计划 | 「Booked · LIB 3/F Room 2」，旁边有 Cancel | Specified，没有接任何预约服务 |
| End the day, stay longer | 这一天的底部 | 提前收掉计划，或者把最后一个停留点延过它的边界 | 这一天收成「That's the day」，旁边有「Not yet」可以回来 | Built，两者都喂给学出来的结束时间 |

**一个 class block 只提供其中一个。** Skip。一节 lecture 不可能被一个正在看卡的学生挪走、缩短或者换教室，所以这个块不假装可以。

**Claim 和 book 是两件事，界面把它们分开。** 普通教室给一个小群体 claim：系统说它会用这个房间，claim 一下就能撤回，撤回把块放回原处。一键预约只在本就对所有人可预约的地方提供。系统分配不到的房间，绝不会被渲染成已分配，所以这是两个行为，不是一个按钮。依据：可用性的那个回答，外加一条还不存在的预约路径。

## 4. 偏离

每个偏离都从一个地方进来，就是屏幕顶部那一行说「Something changed?」的地方，它给的是两句话，不是一个表单。

| 偏离 | 会发生什么 | 你看到什么 | 依据 |
|---|---|---|---|
| 迟到了，还在空白之内 | 打开的停留点边界移动，这一天其余的部分不动 | 卡片就地重写，写「One block changed · the rest untouched (ends 10:46)」 | Specified，algorithm 第 4 节的梯子 |
| 只改这一个 | 只有选中的停留点地点变，目的和时间守住 | 「Moved to KB 221 · only this block changed」 | 数据层，同一性测试是 Specified |
| 超时超掉整个空白 | anchor 赢，停留点被取消，它的时间并进了步行，下一节课迟到到场 | 少一个块，一天变短，没有缩短的课 | Specified，rank 4 加上 L2 里的合并 |
| Undo | 每次写入都记录它替换掉了什么，一点就还原 | 通知上的「Undo」，只在几秒之内 | Built |
| 和完整重算比一比 | 把同一个偏离放进去重算一遍，两个计数都摆出来 | 「see full recompute」，然后「Full recompute: 3 blocks changed」 | Specified，作为一个测试开关 |

这五个共用一种举止。刷新是就地发生的，没有模态，没有确认，也不问为什么。一个要花掉一个对话框的改动，代价比改动本身更大。

跳过一节课不是修复的输入。它是第 3 节里的 skip 动作，planner 绕着它规划，但从不自己产生一个。

这个机制的词是修复，它的停止条件是一个关于「相同」的定义：同样的目的，步行容忍范围内同一栋楼，开始时间在十五分钟以内。任何过不了这个测试的东西，都在坏掉的那个窗口里重新求解，窗口再和它的邻居对一遍，计划其余部分原地不动。依据：[`algorithm.md`](algorithm.zh-CN.md) 第 3、4、5 节。这些在 prototype 里一条都没有，那里一个偏离就是一次固定的边界位移。

## 5. Plan 页

第二个标签页，是提前一天用的，不是当天用的。

| 功能 | 做什么 | 你看到什么 | 依据 |
|---|---|---|---|
| 五个周列 | 把工作周铺成五个窄列，一个块一条 bar | 五列，今天画下划线，bar 带出每一天的形状 | Built |
| 当天列 | 列出选中的那一天，开始时间放在左边距里，地点放在行里 | 时间一路排下去在左边，类型和房间横过来 | Built |
| 开始和结束 | 今天头部的两个可编辑边界 | 「Today from 09:00 until 18:20」，点一颗药丸，从 07:00 到 23:00 里挑一个半点 | Built，而且它喂给揭示 |
| 只有今天可编辑 | 其他每一天都标成只读 | 编辑控件本该在的地方写着「only today can be edited」 | Built |
| 点一个块就改它 | 打开日屏用的同一个 sheet | 四个动作，范围限于那个块 | Built |
| 手动加 | 加一个块，然后把它两边的空白填上 | 「+ Add manually」，一个类型和两个时间 | Built，放置是 Specified |
| 一句话 | 接一段描述出来的改动，先预览它会做什么，再应用 | 「Make tomorrow afternoon study time, back in the lab by 3」，然后「What it did (preview)」和 Apply | Specified，预览今天还只是一行固定文本 |

有两件事比布局更重要。这一页从不显示没解决的块，所以手动加的自习块会先被重新求解到一个房间，才被显示成有房间。这一页编辑的计划就是日屏读的那一份，所以这里的编辑可以在那边撤掉。

## 6. Mine

这里放两样东西，你可以改的参数，和它正在改的参数。

| 功能 | 做什么 | 你看到什么 | 依据 |
|---|---|---|---|
| 可编辑的参数 | 把 planner 读的那些数字摊开，带上当前值 | 步行速度作为一个系数，工作日通常的结束时间，通常的午饭地点，每个都带 Save | Built，被 Specified 的规划消费 |
| 它在学你 | 从动作里推出同样的值，而不是问你要 | 「walk × 1.14 · 3 observations before it replaces the default」 | Specified，没有埋点 |
| 证据有个下限 | 学到的值要三次观察之后才能替换默认值 | 同一行，带上这个计数 | Specified |
| 学习只是默认值 | 学到的值预填一个参数，不撤掉任何控件 | 每个动作都还在屏幕上 | Built，作为一条规则 |

学到了什么，从什么学的。

| 学到的 | 读自 | 变成 |
|---|---|---|
| 你实际走多快 | 你说你迟到时的那个空白 | 更早出发，×1.00 到 ×1.28 |
| 你的一天什么时候结束 | 结束这一天，以及你多常待久一点 | 那个工作日的默认结束时间 |
| 你去哪些地方 | 你改块时挑了哪个选项 | 排到第一位，标成你常去的地方 |
| 你上不上某一节课 | 跳过它 | 这一小时当作只对你一个人空着 |
| 你什么时候吃饭 | 现在挑，还是块之后再挑 | 吃饭的那个窗口 |

让它保持诚实的规则是：学到的东西永远是默认值，永远不是一个被拿走的控件。出勤留在本地，从不聚合，也从不拿来给谁排名。

## 没有做出来的东西

只说一遍，这样上面没有一行会被读得比它实际走得更远。

| 没做出来的 | 会落在哪里 |
|---|---|
| 揭示背后的 planner | [`algorithm.md`](algorithm.zh-CN.md) 第 9 节，stub 每个空白填一个自习停留点 |
| 修复的梯子、同一性测试、邻居检查 | algorithm 第 4、5 节，偏离是一次固定的边界位移 |
| 四个指标 | 没有埋点，所以关于修复的每个数字都是示意 |
| 预订任何东西 | 一键预约 是个标签，后面没有服务 |
| 学习 | 参数可以编辑，还没有任何东西推出它们 |
| 真正的课表 feed | `mock-school-api` 模拟它，学校的 endpoint 没有接 |
| 一份共享的计划 | 计划活在一个浏览器标签页里，所以桌面和手机对不上 |

设计目标是每天一个手势。上面每个功能，要么是朝它走的一步，要么是它身上还没到位的一块。

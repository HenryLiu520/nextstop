# 介面與互動規則

[English](screens.md) · [簡體中文](screens.zh-CN.md) · **繁體中文**

NextStop 是一個頁面，四個 tab。一天是一列塊，塊與塊之間的接縫裡是步行時間。每一個動作都住在它所改動的那個塊裡。

這是 `product/demo/index.html` 已經遵守的約定。原型與本文不一致時，原型勝出，本文被修正。

## 1. 四個 tab，沒有別的

沒有側欄，沒有工具欄，沒有浮動按鈕，沒有搜尋框，也沒有設定抽屜。頁頭是一個 wordmark 和一行日期。列表下面有一行輸入，收一句話，Day 和 Plan 上都有。不是 tab、不是塊、不是接縫、不是 sheet 的東西都是刻意缺失的。

| # | Tab | 放什麼 | 唯一的職責 | 從不包含 |
|---|---|---|---|---|
| 1 | **Day** | 塊、接縫、塊內動作、End the day / Stay longer | 99% 的開啟。你看，你點，你移動 | 表單、文字輸入、聊天記錄 |
| 2 | **Plan** | 帶負載條的周條、點一天、一句話、預覽、應用 | 唯一能改變未來的地方 | 月網格、自動彈出鍵盤、對話記錄 |
| 3 | **Find** | 把原來那個查詢頁整頁嵌進來，看此刻哪幾間空著 | 不離開一天頁就能查房間 | 篩選、地圖、收藏 |
| 4 | **Mine** | 學到的預設值：步行速度、週四通常幾點結束、常去的午飯點 | 首次執行，以及之後你想糾正它時 | 連續打卡、評分、問卷 |

底部條 56px 高，頁面底色，一條 1px 頂邊框，沒有圖示，沒有凸起的 tab。活動 tab 是墨色 `#1C1A17`，標籤正中下方一個 4px 硃紅點，距底 12px。tab 標籤 11.5px，字距 .1em。

## 2. 一天就是塊與接縫

```
  NextStop                        Something changed? Say it
  Thursday · 30 Oct
  ------------------------------------------------
  | 09:00-10:50  Class    COMP1110 · KB             |   past, 40% opacity
       :  Walk 5 min
  +-----------------------------------------------+
  |# 11:00-12:00  Study         KB 227           . |   current, enlarged
  |  You're here · until 12:00                     |
  |  [ Change ]                                    |
  +-----------------------------------------------+
       :  Walk 10 min
  : 12:10-12:40  Lunch    Chong Yuet Ming          :   dotted, not booked
       :  Walk 10 min
  +-----------------------------------------------+
  |# 14:00-15:50  Class    CPD · LG05              |
  |  [ Skip ]                                      |
  +-----------------------------------------------+
       ...

       [ End the day ]   [ Stay longer ]
```

### 2.1 塊的解剖

| 元素 | 規格 |
|---|---|
| 左側豎條 | 4px 寬，上下各內縮 11px，圓角 2，按型別著色 |
| 型別色 | Class `#1C1A17`、Study `#2F5D9E`、Lunch `#B4763A`、Meeting `#6A4C93` |
| 時間 | Georgia，14.5px，`tabular-nums`，寫作 `HH:MM-HH:MM` |
| 型別標籤 | 11px，`#6B655C`，距時間右側 9px |
| 地點 | 13.5px，字重 600，推到右邊緣 |
| 盒子 | 白色，1px `#E2DCCF`，圓角 12，無陰影，內邊距 12 / 14 / 12 / 18 |
| 動作行 | 在塊內，最後一行下方 10px，按鈕之間 9px 間隙 |

### 2.2 三種狀態

| 狀態 | 邊框 | 填充 | 含義 |
|---|---|---|---|
| 實線 | 1px `#E2DCCF` | 白色 | planner 解出來的，所以挪它是我們的事 |
| 虛線 | 1.5px `#C9C0AE` | 白色 | 外部事實：你挪不動的課，已經訂好的房間 |
| 點線 | 1.5px `#BDB4A4` | 透明 | 等待預訂，或等待確認 |

還有兩種外觀疊在這些狀態之上。

過去的塊降到 40% 不透明度，並在它的時間上畫刪除線。它留在列裡，讓這一天保持形狀，點它會回答「那個塊已經過去了」，而不是開啟 sheet。

當前塊是唯一被放大的塊。時間到 26px，左豎條到 5px，內邊距增加 3px，地點之後落一個 6px 硃紅點，新增一行寫著「You're here · until 12:00」。恰好一個塊能擁有那個點。

### 2.3 接縫

接縫上唯一的文字是「Walk N min」。它是一條 16px 的點線豎軌，1.5px `#C9C0AE`，標籤 10.5px `#8C8478`，上下各 9px 空隙，沒有卡片，沒有背景，沒有圓角。寬度是下一個開始減上一個結束，四捨五入到 5 分鐘，下限為 5。

接縫從不說「等」，從不說「空閒」，從不說「沒安排」。空閒時間不是塊與塊之間的空隙。空閒時間會變成一個學習塊。

## 3. 動作矩陣

行是塊的型別。列是從那個塊可達的動作。`block` 表示按鈕就在塊上。`sheet` 表示它是點開塊之後那個 sheet 裡的一行。`no` 表示從不提供。

| 塊 | Skip | Change place | Book it | Nudge time | Remove |
|---|---|---|---|---|---|
| **Class** | `block` | `no` | `no` | `sheet`（±15, ±30） | `sheet` |
| **Study** | `no` | `block` | `no` | `no` | `sheet` |
| **Lunch** | `no` | `block` | `no` | `sheet`（±15, +30） | `sheet` |
| **Meeting** | `no` | `block` | `block` | `sheet`（±15） | `sheet` |
| **End of day** | `no` | `no` | `no` | `no` | `no` |

最後一行用最終塊下面的兩個按鈕取代整套：`End the day` 與 `Stay longer`。兩者都是 1px 墨色描邊的膠囊按鈕。兩者都不用硃紅，因為當前塊上的點已經佔用了它。

一個 class 塊只顯示一個按鈕，`Skip`，意思是「我不去」。跳過不會刪掉那個小時。那個小時變成學習時間，接縫圍繞它重算。

遲到不是頁面級動作。「Something changed?」開啟一個 sheet，裡面兩個 chip，「the class ran 20 min late」與「I am 10 min behind」。兩者都會縮短你正站著的那個塊，並給出一條額外連結「see full recompute」，它存在的唯一目的是讓區域性修復能與全域性修復比較。

## 4. Sheet 與撤銷條

| 部分 | 規格 |
|---|---|
| Sheet | 從底部升起，頂部圓角 18，頁面底色 `#FAF7F2`，左右 20px，底部 26px，最大高度 76%，內部滾動 |
| Veil | `rgba(28,26,23,.28)` 覆蓋頁面，點任何地方關閉 |
| 標題 | 13px 字重 600，讀作 `14:00-15:50 · Class` |
| 行 | 13px，上下內邊距 11px，時間用 Georgia，某行將產出的值靠右 |
| 選擇器 | 恰好 3 個候選加一個 `Change` 去換一批，絕不是 10 個，絕不重複 |
| 撤銷條 | 在導航之上（距底 66px），左右內縮 16px，白色，1px `#E2DCCF`，圓角 12，一句話，硃紅 `Undo` 推到右邊 |

| 動作 | 撤銷條文案 | 撤銷恢復什麼 |
|---|---|---|
| Change place | `Moved to Chi Wah B1 · only this block changed` | 之前的地點 |
| Skip class | `Skipped · that time is now study` | 那節課 |
| Book | `Booked LIB 3/F Room 2 · 16:00-16:50` | 未預訂的那個塊 |
| Remove | `Remove this item` | 那個塊 |
| Repair | `One block changed · the rest untouched (ends 11:40)` | 之前的結束時間 |
| End day | `That is the day · Thursdays usually end at 20:00` | 這一天 |

撤銷條存活 6 秒後離開。同時只有一條，所以第二個動作替換文案，而不是疊出第二條。撤銷是連結，絕不是按鈕，且在可見期間是螢幕上唯一的硃紅。

## 6. 三條規則

**動作屬於塊，不屬於頁面。** 按鈕絕不停在螢幕底部，指望它作用於你最後碰過的東西。如果從按鈕所在的位置看不到它要改動的那件事，那這個按鈕就是錯的。

**硃紅每屏只出現一次。** 它標記那唯一活著的東西：當前塊上的點、活動 tab 的點、撤銷連結，或一條警告。一屏兩個紅標記，說明設計已經答不上「我現在在哪」。

**不存在空時間這種東西。** planner 不留洞，介面也從不畫洞。未預訂的小時變成學習，學習塊拉長去填滿接縫。容許留洞會把產品變回一個課表檢視器。

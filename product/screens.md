# NextStop · 界面规划（A · 纸张 · 终版）

> 界面只有**三个板块**：一天 / 规划 / 我的。
> 一天里面是**一堆块**，块与块之间的缝隙写**串联时间**。
> **动作属于块，不属于页面。**

## 1. 三个板块

> **规划页的顺序是「先看 → 再指 → 最后说」**：看这一周哪里还有余地 → 点那一天和那一段 → 说一句改它。
> 用**周视图不用月视图**：你要排的是"哪一天"，一周就够；月历会逼你先选一次再选一次。

| # | Tab | 装什么 | 唯一入口 | 不许有 |
|---|---|---|---|---|
| **1** | **一天** | 块 + 缝隙 + 动作 + 结束/延长 | 99% 的打开 | 表单、输入框 |
| **2** | **规划** | **① 顶上是一周日历（每条列几根小横杠 = 那天多满）② 点一天 → 下面是那天的列 ③ 空档虚线可点，一点就预填 ④ 最下面说一句 → 预览 → 应用** | 唯一能改未来的地方 | 聊天记录、自动开口、月历 |
| **3** | **我的** | 偏好 · 它在学你的参数（可改）· 通知 · 关于 | 首次 + 想纠正时 | 打卡、评分、问卷 |

**顶栏**：左上角主标题 **NextStop**，下方一行小字日期（`周四 · 10 月 30 日`）。
**导航栏**：底部，56pt，1px 上边框，与页面同色，**无图标、无浮起**；选中态 = 朱红小点。

## 2. 一天 = 块 + 缝隙

```
  NextStop
  周四 · 10 月 30 日
  ────────────────────────────
  ✓ 09:00–10:50  课  COMP1110 · KB     ← 已过（压成细条，40% 透明）
        ┆ 走 5 分钟
  ┌──────────────────────────┐
  │▎11:00–11:50 自习 KB 227 ● │        ← 当前块（放大、朱红点）
  │  你在这                    │
  │  我到了 · 换一个 · 我晚了    │
  └──────────────────────────┘
        ┆ 走 12 分钟
  ┆ 12:10–12:40  吃饭 庄月明     ┆      ← 待订（点线）
        ┆ 多坐 15 分钟也行
  ┌──────────────────────────┐
  │▎14:00–15:50  课  COMP1110  │
  └──────────────────────────┘
        ┆ 走 8 分钟
  ┌──────────────────────────┐
  │▎16:00–17:30 自习 LIB 3/F   │
  └──────────────────────────┘

        ( 结束这一天 )  ( +30 分钟 )
```

### 2.1 块

| 元素 | 规格 |
|---|---|
| 左侧竖条 | 4pt，颜色 = 类型 |
| 时刻 | 宋体，`11:00–11:50` |
| 类型 + 地点 | 一行，地点加粗 |
| 状态 | **实心 = 已求解** / **虚线 = 已排期（外部事实）** / **点线 = 待订** |
| 当前块 | 唯一有朱红点；字大一号；阴影无 |
| 已过的块 | 压成一行细条，40% 透明 |
| 动作 | 块内右下角一行小字，**不浮在页面底部** |

### 2.2 缝隙（串联时间）

细、灰、小字，**不占块**：

| 写法 | 什么时候 |
|---|---|
| `走 5 分钟` | 相邻两站不同楼 |
| 无 | 背靠背，或不跨楼 |

**没有"空着"这回事。** 非走路的时间**默认是自习**并排满 —— 缝隙里只会出现"走 X 分钟"，不会出现"等一会儿""这段没安排"。
理由：允许空档，规划器就退化成"把课表抄一遍"。

## 3. 动作矩阵（按块类型）

| 块类型 | 动作 | 备注 |
|---|---|---|
| **课** | **只有「不去」** | 课不能换、不用确认到达 |
| **自习** | 我到了 · 换一个 · 我晚了 | |
| **吃饭** | 我到了 · 换一个 · 我晚了 | 换 = 换饭点 |
| **见面** | 我到了 · 换一个 · **一键预约** | 换 = 换场地/时间 |
| **末尾** | 结束这一天 · 再待一会儿 | 唯一的"收"动作 |

**「我晚了」挂在下一个块上**：课拖堂，回到界面看到的那一块正好带着它。

---

## 4. 改动如何传播

1. 你改了某一块
2. 后面的块**逐块检查"还成不成立"**
3. 成立的**一个像素都不动**
4. 不成立的**只改最小的一处**
5. **不得不改超过 2 块 → 明说**：`改了 3 站，要不我换种安排？`

**最小改变不是悄悄改很多，而是改得多就告诉你。**

### 4.1 代价顺序（"最小"的可执行定义）

| 改动 | 代价 | 顺序 |
|---|---|---|
| 挪 5–10 分钟 | 最低 | ① 先试 |
| 换房间（同楼） | 低 | ② |
| 换楼 | 中 | ③ |
| 取消一整站 | 高 | ④ 尽量不 |
| 改变出勤（不去/去了） | **最高** | 只由用户决定，系统永不擅自 |

## 5. 换一个（吃饭 / 自习 / 见面共用）

底部升起一张纸：

| 规则 | 说明 |
|---|---|
| 一次三个候选 | 不是十个 |
| 每个必带**「最晚几点必须走」** | 这才是真约束 |
| `换一批` | 排除已看过的，**永不重复** |
| 最多换三次 | 之后：`附近就这些了，要不换个时间？` |
| 点选即生效 | 不再点确认 |
| 自动重排 | 按 §4 传播 |
| 撤回 | 底部一行：`已换到智华馆 B1 · 撤回` |

## 6. 一键预约（只在"见面"块）

```
      [ 一键预约 ]      [ 已预约 ]
```

| 状态 | 显示 | 块 |
|---|---|---|
| 待订 | `[一键预约] [已预约]` | 点线 |
| 预约中 | `[订呢…]` | 虚线 |
| 成功 | `[已预约 · LIB 3/F 讨论室 2]` + 取消（收在 ⋯） | **变实心** |
| 失败 | `[没订到 · 换时间]` + 一句原因 | 点线 + 红字 |

**「已预约」不是按钮，是状态。** 只有本就可预约的空间才有这个按钮；普通教室只给"认领"。

## 7. 结束 / 延长（末尾双钮）

| | |
|---|---|
| 样式 | 两个 1px 墨黑描边圆钮，**不用朱红** |
| 结束这一天 | 收尾 → 记一条观测 → 归档 |
| 再待一会儿 | +30，长按可选 15/30/60 |
| 按钮 | **永久保留**，学到的只是默认值 |

## 8. 学习：三条主线 + 两条辅助

| 学什么 | 从哪个动作 | 闸门 | 默认值怎么变 | 按钮 |
|---|---|---|---|---|
| **结束时间** | 结束这一天 | 同一星期几满 3 次 | 周四 17:00 → 20:00 | 保留 |
| **延长时间** | 再待一会儿 | 满 3 次 | 终点后移 | 保留 |
| **常去的点** | 换一个里选了哪个 | 满 3 次 | 候选第一位 + `你常去` | 保留 |
| **出勤倾向** | 不去 | 满 3 次 | 那一小时默认当可用 | 保留（并变 `我去了`） |
| 走路系数 | 我晚了 | 满 3 次 | 提前出发 ×1.00 → ×1.28 | 可改 |
| 到校时间 | 揭开时刻 | 满 3 次 | 默认开始时间 | 可改 |

### 8.1 三条护栏

1. **学到的永远是默认值，不是被拿走的按钮**
2. **课表不动**：学到的只是"你不在"，不是"这节课不存在"
3. **只存本地、不评价、不汇总**

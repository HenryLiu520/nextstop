# NextStop · 功能概要

> 学生走出教室，真正卡住的不是“哪儿有空房”，是“接下来这一小时干什么”。
> 这份文件只回答一件事：**打开它，会发生什么。**

---

## 0. 一句话

**一个会替一个学生决定当天每一段空隙、并在现实偏离时只改最少部分的 app，内置一个能替他用自然语言操作同一个 app 的 AI。**

---

## 1. 主流程（一天只发生一次的事）

```
① 下课 → 打开 app → 首屏没有空白表单，只有一张卡
                      ↓（第一次打开，瞬间）
② 揭开今日日程  ← 此刻取一次定位，从"现在"算到最后一件有承诺的事
                      ↓
③ 一张卡                 「现在去 KB 227，走 5 分钟，10:55 离开」
   下方"今日带"           09:00 课 · 10:00 自习 · 12:10 吃饭 · 14:00 课
                      ↓
④ 执行                  点"我到了" → 下一站自动提前 → 卡片换掉
                      ↓
⑤ 偏离                  拖堂 / 晚了 / 想换个地方 / 想去吃饭 / 翘课
                      ↓
⑥ 修复                  只改被影响的那一站，其余不动，inline 刷新，可撤回
                      ↓
⑦ 夜里（可选）          和 AI 聊两句，定明天的偏好；白天它从不主动说话
```

**核心规则**：一天没有“开始时间”，只有**开始的那一刻**。之后打开只读，只有偏离才触发计算。

## 2. 功能清单

### A. 揭开与规划

| 功能 | 行为 | 证据（怎么看见） |
|---|---|---|
| **一次揭开** | 当天第一次打开时规划，之后打开只读 | 第二次打开不再重算（日志可见） |
| **一次定位** | 只在揭开时读一次位置，不追踪 | 后续操作无定位调用 |
| **无定位回退** | 优先用“上一节课在哪”，否则给三个楼栋选项（当天唯一可能要点的） | 断定位仍可用 |
| **算到最后承诺** | 终点 = 当天最后一件有承诺的事，不是固定放学时间 | 换课表，终点跟着变 |

### B. 五种停靠点

| 类型 | 内容 | 备注 |
|---|---|---|
| **study** | 自习/写作业，指定楼栋+房间 | 用可用性引擎选房 |
| **meet** | 见人/讨论，按人数分三层（见 F） | |
| **eat** | 吃饭，见 G | |
| **transit** | 走路本身（同一栋楼不算一站） | 跨楼时间已计入 |
| ~~wait~~ | **不存在**：不允许出现“等一会儿”这种停靠点 | 空隙要么被填，要么被合并 |

### C. 执行与三类偏离

| 偏离 | 触发方式 | 系统反应 |
|---|---|---|
| **拖堂 / 我晚了** | 点一下，或说一句 | 重算受影响窗口，其余不动 |
| **换一个** | 点“换一个” | 换的是**这一站**，不是整天 |
| **翘课** | 点“不去” | 撤回个人承诺：课照上、房照占，只改“你在不在” |

**共有一条**：全部 **inline 刷新**，可撤回，不弹窗、不确认、不问原因。

### D. 修复（技术核心）

| 功能 | 行为 |
|---|---|
| **“同一件事”判据** | 目的不变 ∧ 地点同楼或步行容忍内 ∧ 开始时间 ±15 分钟内 |
| **最小扰动** | 只重解被破坏的窗口，`keep` 部分永不重新优化 |
| **级联保护** | 修完检查相邻一站，避免连锁改动 |
| **对照能力** | 同一偏离可切换“全部重算”以对比（评测用） |

### E. 学习（一周 shadow mode）

| 学的量 | 从哪读 | 上闸条件 |
|---|---|---|
| 走路系数 | “我晚了”的差值 | ≥3 次观测 |
| 到校 / 离校分布 | 打开时间、当天最后一次交互 | ≥3 次 |
| 时间容忍度 | “换一个”的频率与时机 | ≥3 次 |
| 翘课倾向 | “不去”的分布（**只存本地，不统计**） | ≥3 次 |
| 吃饭时段与偏好 | 选“现在吃”还是“写完再吃” | ≥3 次 |

**铁则**：每次适应只改**参数或权重**，从不改规划算法。界面标一句“还在学你”。

### F. meet 三层

| 规模 | 场地 | 系统做什么 |
|---|---|---|
| 2–4 人 | 普通教室（L1 空闲池） | 认领 → 可撤回 → 失败重规划 |
| 5–10 人 | 本来就允许预约的空间 | 只算“何时该订” + 把结果当事实贴回 |
| >10 人 | 同上 | 同上，并提示提前量 |

> 我们不能分配的房间，系统不假装能分配。

### G. eat

| 功能 | 行为 |
|---|---|
| **静态点表** | 8–12 个点：名字 / 楼 / 步行分钟 / 时段档位 / 大致容量 |
| **不预测时长** | 改算**最晚几点必须走**（deadline） |
| **弹性区间** | 可行性用 max、显示用 typical、实际用 min，结余还给下一站 |
| **两条建议** | “现在吃”和“写完再吃”，因为“饿不饿”只有你知道 |
| **拥挤度** | 由课表推（哪几门课几点下课、离哪个食堂近），标为**估计** |

### H. 内置 AI agent（MCP 工具面）

| 组 | 工具 | 对应界面动作 |
|---|---|---|
| 读 | `get_plan` `get_gaps` `get_availability` `get_walking` | 一眼看今天 |
| 排 | `replan` `insert_stop` `remove_stop` `set_constraint` `set_preference` | 拖动 / 换一个 |
| 执行 | `arrive` `retract` | “我到了” / “不去” |
| 外部 | `book_room` | 一键预约 |

**原则**：**AI 的能力 = 界面的能力，一分不多。** 工具 12 个封顶；每个工具必须对应一个界面动作。

**约束**：只能 `propose`（预览一步）→ `apply`；所有写入过同一个校验器；改参数不改算法；有副作用的三件事必须确认。

**等价性测试（写进报告）**：同一动作，走界面路径与走 AI 路径，最终状态必须完全相同。

### I. 界面

| 屏幕 | 内容 | 不做 |
|---|---|---|
| **首屏** | 一张卡（零点击）+ 下方今日带（3–5 个点） | 不做空白表单，不做“点一下才展开” |
| **今日带** | 压缩的一整天，点开是**读**不是**填** | 不做可编辑时间轴 |
| **夜里** | 可选对话（2 个吃法 + 理由） | 白天不出现任何对话 |
| **状态标记** | 实心=已求解 / 虚线=已排期（外部事实）/ 点线=待订 | **绝不出现“你自己填的、它没验过”的块** |

## 3. 状态机

```
   planning ──揭开──> executing ──偏离──> deviated ──> repairing ──> executing
       ↑                                                              │
       └──────────────────── 次日揭开 ──────────────────────────────┘
```

- 只有四个状态，**没有第五个**
- `repairing` 是唯一会改动计划的状态
- 一切状态转换都记一条事件（可回放）

---

## 4. 输入与依赖

| 输入 | 来源 | 是否必需 |
|---|---|---|
| 课表 | 学校发布的只读 feed（**永远正确，不作为怀疑对象**） | 必需 |
| 位置 | 揭开时读一次；失败则两级回退 | 可选 |
| 偏好档案 | **一次性**（可说的，也可填的） | 必需（有默认值） |
| 走路时间 | 静态矩阵（楼栋两两之间） | 必需 |
| 吃饭点 | 手工 8–12 条 | 必需 |
| 房间可用性 | 已有引擎从课表推导 | 必需 |

---

## 5. 不做清单（有意的）

1. 不做“查空房”——那是零件，不是产品
2. 不做日历那样的“你自己填”
3. 不做白天对话 / 推送 / 提醒
4. 不评价人、不排序人、不显示姓名房号
5. 不质疑课表
6. 不做多用户、不做权限、不做部署（不计分）
7. 不做传感器、不做室内定位

---

## 6. 一页总结

| 维度 | 一句话 |
|---|---|
| **产品** | app |
| **用户看到** | 一张卡 |
| **用户的动作** | 一天一次（揭开）+ 偶尔一次（我到了 / 换一个 / 不去） |
| **系统做的** | 算、排、修、学 |
| **AI 的角色** | 坐在旁边的第二个用户，能做的和你能点的完全一样 |
| **最硬的一处** | 修复：只改最少的那一站 |
| **最容易被记住的一处** | 学你走多慢，而不是问你走多快 |
